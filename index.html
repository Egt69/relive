    How staking works

    Plain-English primer

    01

    Stake PIE, back a node

    Holders lock PIE behind Suits, Keepers or Workers. The stake stays in their wallet; only the minimum is held while the node is active.

    02

    Nodes earn, stakers earn

    Validating nodes collect gas rewards, which are split between the node operator and the stakers backing it.

    03

    Exit whenever you want

    Unstake to release PIE. Removing a node from the network frees its held stake so it can be unstaked.

    Stake and unstake totals come from the network's all-time transaction ledger. Per-wallet staking rewards can be queried in the Explorer.
